# CodeAlpha Data Visualization Project

## Project Overview
This project focuses on visualizing a Books Dataset containing 1,000 book records using Python. The main objective is to present data patterns and trends through different charts and visualizations.

## Dataset Information
The dataset contains the following columns:
- Title
- Price
- Rating
- Availability

Total Records: 1,000 books.

## Tools and Libraries Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created
1. Book Rating Distribution
2. Book Price Distribution
3. Average Book Price
4. Book Price Comparison by Rating
5. Average Book Price by Rating
6. Book Availability Analysis
7. Book Availability Pie Chart
8. Correlation Heatmap

## Key Findings
- The dataset contains 1,000 books.
- No missing values were found.
- No duplicate records were found.
- The average book price is 35.07.
- The average book rating is 2.923 out of 5.
- All 1,000 books are listed as In stock.
- Different visualizations were used to explore price, rating, and availability patterns.

## Conclusion
Data visualization helps present complex information in an understandable graphical format. Using Matplotlib and Seaborn, different charts were created to analyze book prices, ratings, and availability.
